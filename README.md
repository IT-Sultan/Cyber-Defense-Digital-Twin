# Cyber Defense Digital Twin

AI-assisted cybersecurity platform for threat detection, event correlation, and attack analysis.

## Project Goal

Build a prototype SOC platform that analyzes cybersecurity telemetry and detects suspicious activity.

## MVP

The first version will:

- Process cybersecurity telemetry
- Detect suspicious events
- Correlate related events
- Map activity to MITRE ATT&CK
- Build an attack timeline
- Generate SOC alerts

## Dataset

Initial dataset: APTsDataset

We will start with one attack campaign before expanding to additional scenarios.
