# MITRE ATT&CK Mapping

This module maps detected and correlated activity to MITRE ATT&CK techniques.

## Responsibilities

- Map detections to MITRE ATT&CK techniques
- Identify tactics and techniques
- Link attack stages
- Enrich alerts with MITRE information
- Support attack timeline analysis

## Input

Detected and correlated security events

## Output

MITRE ATT&CK mapped events and techniques
