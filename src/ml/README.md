# Machine Learning

This module handles machine learning and anomaly detection.

## Responsibilities

- Select useful model features
- Prepare model inputs
- Train baseline models
- Detect anomalous behavior
- Evaluate model performance
- Tune detection thresholds

## Evaluation

Main metrics:

- Precision
- Recall
- F1 Score
- False Positive Rate

## Input

Cleaned and structured cybersecurity events

## Output

Anomaly scores and model predictions
