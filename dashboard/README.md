# SOC Dashboard

This module provides the main interface for visualizing security analysis results.

## Responsibilities

- Display security alerts
- Show attack timelines
- Visualize attack graphs
- Display MITRE ATT&CK techniques
- Show anomaly scores and severity
- Support SOC investigation workflow

## Input

Detections
Machine learning results
Correlated events
MITRE ATT&CK mappings
Attack graph data

## Output

Interactive SOC dashboard
