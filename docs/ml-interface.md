# ML Integration Contract

## ML Input

The ML module will use cleaned cybersecurity events generated by the preprocessing pipeline.

Input:
data/processed/apt41_clean.csv

## Required ML Output

Each event should contain:

- event_id
- @timestamp
- host
- ml_score
- ml_label
- model_name

## Important Rules

- technique must not be used as an input feature
- tactic must not be used as an input feature
- technique and tactic may be used only as ground truth for evaluation
- the ML module must not modify the cleaned source dataset

## Expected Output

data/processed/ml_predictions.csv

## Integration

ML predictions will be combined with:

- Detection Engine
- Event Correlation
- MITRE ATT&CK
- Attack Graph
- SOC Risk Score
