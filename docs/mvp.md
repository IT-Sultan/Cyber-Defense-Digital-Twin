# MVP Scope

## Dataset
APTsDataset

## Goal
Build the first working version of the Cyber Defense Digital Twin using one attack campaign.

## First Scenario
Analyze one attack campaign from raw security events to a final SOC alert.

## Pipeline

Raw Events
→ Data Cleaning
→ Feature Engineering
→ Detection
→ Machine Learning
→ Event Correlation
→ MITRE ATT&CK Mapping
→ Attack Timeline
→ SOC Alert

## Current Plan

1. Inspect the dataset structure
2. Select one attack campaign
3. Clean and prepare the data
4. Identify useful features
5. Build a baseline detection model
6. Correlate related security events
7. Map detected activity to MITRE ATT&CK
8. Build the attack timeline
9. Generate the final SOC alert
